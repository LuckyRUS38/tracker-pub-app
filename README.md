# Huly Desktop

Десктопное приложение-оболочка для Huly (Windows, macOS, Linux). Исходники приватные, здесь только релизы и инструкция.

## Установка
Скачай файл для своей системы из [Releases](../../releases/latest):

| Система | Файл |
|---|---|
| Windows | `*-setup.exe` |
| macOS (Apple Silicon: M1/M2/M3/M4) | `*_aarch64.dmg` |
| macOS (Intel) | `*_x64.dmg` |
| Linux (любой дистрибутив, в т.ч. Arch) | `*.AppImage` |
| Debian/Ubuntu | `*.deb` |
| Fedora/openSUSE | `*.rpm` |

### Windows
Установщик не подписан, поэтому SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».

### macOS
Приложение не подписано сертификатом Apple. После переноса в «Программы» выполни один раз:
```bash
xattr -cr "/Applications/Huly Desktop.app"
```
Если macOS всё равно блокирует: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

### Linux
```bash
chmod +x Huly*.AppImage
./Huly*.AppImage
```
Arch: `sudo pacman -S webkit2gtk-4.1 libappindicator-gtk3`. Если окно пустое или падает: `WEBKIT_DISABLE_DMABUF_RENDERER=1 ./Huly*.AppImage`.

## Обновления
Приложение само проверяет обновления при запуске и раз в 6 часов, скачивает и перезапускается. Вручную: значок в трее → «Проверить обновления».

## Трей и уведомления
Закрытие окна сворачивает приложение в трей, оно продолжает получать уведомления. Выйти — значок в трее → «Выйти». Автозапуск включается там же.
