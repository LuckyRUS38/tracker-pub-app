# Huly Desktop

Десктопное приложение-оболочка для Huly (Windows, macOS, Linux). Исходники приватные, здесь только релизы и инструкция.

## Установка
Скачай файл для своей системы из [Releases](../../releases/latest):

| Система | Файл |
|---|---|
| Windows | `*-setup.exe` |
| macOS (Apple Silicon: M1/M2/M3/M4) | `*_aarch64.dmg` |
| macOS (Intel) | `*_x64.dmg` |
| Linux (любой дистрибутив, в т.ч. Arch) | `*.AppImage` |
| Debian/Ubuntu | `*.deb` |
| Fedora/openSUSE | `*.rpm` |

### Windows
Установщик не подписан, поэтому SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».

### macOS
Приложение не подписано сертификатом Apple. После переноса в «Программы» выполни один раз:
```bash
xattr -cr "/Applications/Huly Desktop.app"
```
Если macOS всё равно блокирует: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

### Linux
```bash
chmod +x Huly*.AppImage
./Huly*.AppImage
```
Arch: `sudo pacman -S webkit2gtk-4.1 libayatana-appindicator`. Для уведомлений на Sway / Hyprland / i3 нужен демон (`mako`, `dunst`, `swaync`). Если окно пустое или мерцает: `HULY_SAFE_RENDER=1 ./Huly*.AppImage`, затем `HULY_X11=1`. Настройки Wayland, трей, пакет для pacman и частые проблемы: [LINUX.md](LINUX.md).

## Обновления
Приложение само проверяет обновления при запуске и раз в 6 часов, скачивает и перезапускается. Вручную: значок в трее → «Проверить обновления».

## Горячие клавиши
Памятка со всеми сочетаниями: клавиша **?** (или **F1**), либо меню аккаунта → «Горячие клавиши». Главное:

| Сочетание | Действие |
|---|---|
| **G**, затем **I / T / D / F / C / P / S / O** | перейти во Входящие, Трекер, Документы, Drive, Чат, Планировщик, Сводку, Настройки |
| **Ctrl+K** (на Mac **⌘K**) | палитра команд Huly |
| **Ctrl+Alt+H** | показать или скрыть окно из любого места системы (только десктоп) |
| **Ctrl+Tab**, **Ctrl+Shift+Tab**, **Ctrl+T**, **Ctrl+W** | следующая и предыдущая вкладка, новая, закрыть (только десктоп) |
| **← →**, **D / W / M**, **T**, **C** на странице «Сводка» | период, день/неделя/месяц, сегодня, копировать итоги |
| **N** в папке Drive | новый файл |
| **Ctrl+S**, **Ctrl+E** в редакторе файла | сохранить; визуальный редактор или исходный текст |

Буквенные сочетания работают, пока фокус не в текстовом поле. Они не зависят от раскладки клавиатуры.

## Память, процессы и энергия
Приложению нужно оставаться живым в трее, чтобы приходили уведомления, поэтому экономия достигается тем, что **не нужно делать**:
- **Синхронизация Drive сама замедляется.** Пока что-то происходит, сервер опрашивается каждые 30 секунд. Если несколько проходов подряд ничего не изменилось, интервал удваивается (60 с, 2 мин) до 5 минут. Правка файла, ручная синхронизация или окно приложения на переднем плане возвращают короткий интервал. Изменения из Drive на других устройствах при долгом покое подхватываются с задержкой до 5 минут.
- **Windows:** когда окно убрано в трей, WebView2 переводится в режим низкого потребления памяти. Страница продолжает работать, уведомления приходят. При открытии окна возвращается обычный режим.
- **Меньше пробуждений процессора** (все системы): счётчик непрочитанного раньше срабатывал на каждое изменение интерфейса Huly и обращался к нативной части сотни раз в секунду, теперь следит только за заголовком страницы и сообщает лишь об изменившемся числе. Определение текущего пространства работает по событиям истории браузера, а не по таймеру каждые 2 секунды.
- **macOS, батарея:** на питании от батареи и в режиме низкого энергопотребления (Low Power Mode) экономный режим включается сам и выключается при подключении к сети (проверка раз в минуту через `pmset`). Отключить автоматику: значок в трее → снять «Включать экономный режим на батарее». Автоматический режим не закрывает окна других пространств (это бы мешало работе при каждом отключении от сети), он убирает анимации и реже опрашивает Drive; полностью отключить окна других пространств можно вручную режимом «Экономный режим». То же автоматическое поведение работает на Windows и Linux-ноутбуках.
- **Что на macOS сделать нельзя:** у WKWebView нет переключателя памяти, как у WebView2 в Windows. Скрытое окно система притормаживает сама (App Nap), приложение этому не мешает.
- **Экономный режим** (значок в трее → «Экономный режим»): выключает скрытые окна других пространств (самая большая необязательная трата: отдельные процессы браузера), убирает анимации и переходы в интерфейсе и делает опрос синхронизации реже (от 60 секунд до 10 минут). Что у вас было включено раньше, запоминается и возвращается при выключении режима. В экономном режиме нет уведомлений из других пространств.

## Трей и уведомления
Закрытие окна сворачивает приложение в трей, оно продолжает получать уведомления (на Linux без системного трея закрытие окна завершает приложение). Выйти — значок в трее → «Выйти». Автозапуск включается там же.
